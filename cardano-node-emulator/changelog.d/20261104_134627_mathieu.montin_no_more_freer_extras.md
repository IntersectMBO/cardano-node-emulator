### Added

- Added `Cardano.Node.Emulator.Log`, providing Polysemy logging and observation effects, convenience operations, and interpreters for tracing, writing, rendering, and ignoring messages.

### Changed

- Migrated emulator operations and chain processing from the MTL/Freer API to Polysemy. Operations now use `Sem` with `ConcreteEmulatorEffs`, and `EmulatorError` is an `Exception` in the error effect.
- Renamed the node parameter type from `Params` to `EmulatorParams`.

### Removed

- Removed the `MonadEmulator`, `EmulatorT`, and `EmulatorM` interfaces and the `freer-extras`, `freer-simple`, and `mtl` dependencies; callers must use and interpret the Polysemy effects.
