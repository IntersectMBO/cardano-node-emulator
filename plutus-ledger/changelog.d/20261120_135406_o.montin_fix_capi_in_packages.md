### Removed

- Removed the `ToCardanoScriptHash` class; use `hashVersionedScript` to obtain
  the Cardano script hash of a versioned Plutus script.

### Added

- Added JSON and CBOR serialization instances for Plutus V3 `TxId` and
  `TxOutRef`, and JSON serialization for Cardano signing keys.
