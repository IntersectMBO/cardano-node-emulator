### Added

- `ToJSON`/`FromJSON` instances for the emulator mock wallets
  (`MockWallet`, `MockPrivateKey` and the new `WalletDigest` wrapper) in
  `Ledger.CardanoWallet`, so wallets can be serialised to and from JSON.
- An `Eq` instance for `MockWallet`.
- A test checking the JSON round-trip of the known mock wallets.

### Changed

- The `mwWalletId` field of `MockWallet` is now a dedicated `WalletDigest`
  newtype (wrapping the Blake2b-160 digest) instead of a bare
  `Crypto.Digest Crypto.Blake2b_160`.
