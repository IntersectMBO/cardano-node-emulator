### Changed

- Migrated socket server command processing, ChainSync state handling, Conway queries, and emulator-state execution from `EmulatorT`/MTL to Polysemy.
- Migrated trace logging and log-observation handlers in `Plutus.Monitoring.Util` to the Polysemy `LogMsg` and `LogObserve` effects.
- Updated socket configuration and state APIs to use `EmulatorParams` instead of `Params`.
- Replaced the `freer-extras`, `freer-simple`, and `mtl` dependencies with `polysemy` and `polysemy-plugin`; the executable also depends on the plugin and Polysemy.
